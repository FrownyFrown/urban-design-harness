# 05. 법규·실현성 검증 (Regulation & Feasibility — 한국)

> 목표: 설계안이 법적으로 가능하고, 단계적으로 실현 가능함을 보인다.
> 법규는 제약이 아니라 **논거**다. "상위계획이 이미 이 방향을 지정했다"는 가장 강한 설득이다.
> ※ 수치·제도는 개정 가능 — 실무 인용 전 국가법령정보센터(law.go.kr)·해당 지자체 조례 확인.

---

## 1. 한국 공간계획 체계 (위계)

```
국토종합계획
 └ 도종합계획 / 수도권정비계획
    └ 도시·군기본계획  (20년 장기, 방향 제시 — 구속력은 행정 내부)
       └ 도시·군관리계획 (법적 구속력: 용도지역·지구·구역, 기반시설, 지구단위계획, 정비계획)
          └ 지구단위계획 (특정 구역 맞춤 규제: 용도·밀도·높이·배치·형태)
```
+ 생활권계획(서울 등 대도시): 기본계획과 관리계획 사이에서 지역 단위 방향 제시.

**설계 논거 활용법**: 대상지가 지구단위계획구역이면 → 계획 결정 연도·지정 취지·권장 용도를 인용해 "본 제안은 ○○지구단위계획(연도)이 지정한 ○○ 방향을 구체화한 것"으로 프레이밍.

---

## 2. 용도지역별 밀도 한도 (국토계획법 시행령 상한 — 지자체 조례로 하향 가능)

| 용도지역 | 건폐율 | 용적률 상한 | 비고 |
|---|---|---|---|
| 제1종전용주거 | 50% | 100% | 단독 중심 |
| 제2종전용주거 | 50% | 150% | |
| 제1종일반주거 | 60% | 200% | 저층(4층 이하 관행) |
| 제2종일반주거 | 60% | 250% | 서울 조례 200% 등 하향 多 |
| 제3종일반주거 | 50% | 300% | 서울 조례 250% 등 |
| 준주거 | 70% | 500% | 역세권 복합에 빈용 |
| 근린상업 | 70% | 900% | |
| 일반상업 | 80% | 1,300% | 서울 조례 800% 등 |
| 중심상업 | 90% | 1,500% | |
| 준공업 | 70% | 400% | 서울 준공업 관리 별도 지침 |
| 자연녹지 | 20% | 100% | |

체크 순서: ① 토지이음에서 용도지역 확인 → ② 해당 지자체 조례 한도 확인 → ③ 지구단위계획 별도 지침 확인 (조례보다 우선 적용되는 완화/강화 있음).

높이 제한 계열: 정북방향 일조 사선(전용·일반주거), 가로구역별 최고높이, 문화재 앙각, 비행안전구역 — 대상지별로 해당 여부만 빠르게 스크리닝.

## 3. 용적률 인센티브·공공기여 구조

기본 논리: **공공이 원하는 것(공공시설·임대주택·개방공간)을 제공 ↔ 용적률·높이 완화**

| 수단 | 내용 |
|---|---|
| 지구단위계획 용적률 체계 | 기준용적률 → (공공기여 시) 허용 → (특별 항목) 상한용적률 |
| 공개공지 | 일정 규모 이상 건축 시 의무 + 초과 제공 시 완화 |
| 기부채납 | 도로·공원·공공시설 부지/건물 제공 ↔ 완화 협상 |
| 역세권 활성화 | 역세권 용도지역 상향 + 공공기여 환수 |
| 사전협상제 (서울, 대규모 부지) | 1만㎡+ 부지 용도 변경 ↔ 공공기여 협상 |

설계 적용: 대규모 이전적지 제안에서는 "용도지역 상향(예: 준공업→준주거) + 공공기여(공원·문화시설 ○○㎡)"를 한 쌍으로 제시하면 실현 시나리오가 완성된다.

---

## 4. 사업 방식 스크리닝

| 방식 | 적용 상황 | 핵심 변수 |
|---|---|---|
| 민간 개발 (단일 지주) | 이전적지·대형 단일 소유 | 인허가 + 공공기여 협상 |
| 도시정비사업 (재개발·재건축) | 노후 다수 지주 | 노후도 요건, 조합 동의율(3/4 등) |
| 가로주택·소규모정비 | 소블록 단위 | 빠른 절차, 규모 한계 |
| 도시개발사업 | 미개발지 환지/수용 | 대규모, 장기 |
| 공공 주도 (LH/SH 등) | 공공주택·복합 거점 | 속도, 주민 수용성 |

과제·제안서에서는 "본 안은 ○○ 방식을 전제로 하며, 1단계(공공 선도) → 2단계(민간 유치) → 3단계(완성)"의 **Phasing 다이어그램**까지 제시하면 실현성 점수를 얻는다.

---

## 5. Phasing (단계별 실행) 설계 원칙

1. **1단계는 공공·저비용·가시성**: 가로 개선, 공원, 임시 활용(팝업) — 신뢰와 수요를 먼저 만든다
2. 앵커 시설은 1~2단계에: 후속 민간 투자를 견인
3. 각 단계가 **그 자체로 완결**되게: 2단계가 무산돼도 1단계만으로 동네가 좋아져야 함
4. 단계별 재원·주체 표기: (공공예산/민간/기금)

---

## 6. 실현성 리스크 체크리스트
- [ ] 용도지역·조례 한도 내 (또는 완화 경로 명시)
- [ ] 지구단위계획 지침 정합 (있다면 인용)
- [ ] 일조·높이 규제 1차 스크리닝
- [ ] 기반시설 용량 (학교·주차·하수 — 유발 인구 역산 결과와 대조)
- [ ] 공공기여 패키지 정의
- [ ] 사업 방식 + 3단계 Phasing
- [ ] 기존 이해관계자(주민·상인·지주) 영향과 대응 1줄씩
