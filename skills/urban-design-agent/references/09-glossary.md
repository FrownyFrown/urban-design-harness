# 09. 용어·단위 사전 (Glossary & Conversions)

## 1. 핵심 용어 (한–영–한 줄 정의)

| 한국어 | 영어 | 정의 |
|---|---|---|

| 대지면적 | Site Area | 건축 가능한 필지 면적 |
| 용도지역 | Zoning (Use District) | 토지이용·밀도를 정하는 법정 구역 |
| 지구단위계획 | District Unit Plan | 특정 구역 맞춤 상세계획 (한국 고유 제도) |

| 공개공지 | Public Open Space (POPS) | 민간 대지 내 공중 개방 공간 |

| 역세권 | Station Influence Area | 통상 역 반경 350~500m |

| 보행 동선 | Pedestrian Circulation | |
| 결절점 | Node | 활동·동선이 모이는 점 |

## 2. 단위 환산

| 항목 | 환산 |
|---|---|
| 1평 | 3.3058㎡ |
| 1ha | 10,000㎡ ≈ 3,025평 |
| 1에이커 | 약 4,047㎡ |
| 도보 속도 | 약 4.8km/h (계획 관행 80m/분) |
| 도보 5/10/15분 | 약 400 / 800 / 1,200m (직선반경, 실거리 ×1.3 보정) |
| 자전거 15분 | 약 3km |
| 1개 층고 | 주거 약 3m, 업무 약 4m, 상업 1층 4.5~6m |
| 보도 최소폭 | 2m (법정), 쾌적 3m+ |
| 차로 폭 | 3.0~3.5m/차로 |
| 가구원수 | 서울 평균 약 2.1인/가구 (인용 시 최신 확인) |

## 3. 비전문가 번역 표 (질문할 때 쓰는 일상어)

| 전문 질문 | 일상어 버전 |
|---|---|
| 대상지 경계와 면적은? | 어느 동네, 어디서 어디까지인가요? |
| 과업 범위는? | 아이디어만 필요해요, 아니면 도면·발표자료까지요? |
| 상위계획 정합성은? | 시청이 이 동네에 세워둔 계획이 있는지 같이 찾아볼게요 |
| 타겟 인구는? | 누가 주로 쓰면 좋겠어요? (아이 키우는 집, 직장인, 어르신…) |
| 용적률 한도는? | 이 땅에 법적으로 얼마나 크게 지을 수 있는지 확인할게요 |
