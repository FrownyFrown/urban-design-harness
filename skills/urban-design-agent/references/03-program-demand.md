# 03. 프로그램·수요 설계 (Programming & Demand)

> 목표: "무엇을 얼마나 넣을지"를 데이터로 결정한다. 시설 목록은 취향이 아니라 **수요 계산의 결과**여야 한다.

---

## 1. 4-Layer 논리 구조 (모든 시설 제안의 통과 의례)

### Layer 1 — 맥락 (Who lives here?)
수집: 인구 구성(연령·가구), 직업·생활 패턴(출퇴근·재택), 이동수단 분담률, 주변 인프라 유무
결론 형식: "이 동네 ○○대 인구(○○%)는 ○○이 부족하고, 현재 ○○분을 이동해야 ○○을 이용할 수 있다."

### Layer 2 — 수요 (Why here, why this?)
수집: 반경 내 유사시설 공백, 5/10/15분 접근 분석, 타겟 인구 규모, 비교 사례
결론 형식: "반경 ○m 내 ○명 거주, 가장 가까운 ○○까지 ○분 → 신설 시 ○분으로 단축."

### Layer 3 — 작동 (How does it work?)
- 면적 = 타겟 인구 × 1인당 기준 면적
- 이용 패턴: 피크타임, 회전율(시간당 이용), 계절 변동
- 동선: 보행/차량 분리, 교통약자 경로, 자전거 주차

### Layer 4 — 효과 (So what?)
측정 지표: 도보 접근 인구 증가율(%), 15분 내 도달 시설 수 변화, 이동거리 감소(m), 커버 인구 비율(%)
결론 형식: "반경 ○m 내 ○명(전체 ○%)이 도보 15분 내 접근 가능해지며, ○○ 원칙/상위계획에 부합한다."

## 2. 시설별 면적 기준 (한국 법정·계획 기준)

| 공공도서관 | 봉사인구 기준 연면적 단계표 (예: 인구 2~5만 → 1,650㎡~) | 도서관법 시행령 |

## 3. 개발 규모 산정 (연면적 → 프로그램 배분)

```
대지면적 × 용적률 = 지상 연면적 한도
지상 연면적 × 용도 배분율 = 용도별 면적
용도별 면적 ÷ 단위 기준 = 수용량
```

예시 (대지 40,000㎡, 용적률 400% 가정):
- 연면적 한도 160,000㎡
- 배분: 주거 50%(80,000㎡ → 전용+공용 환산 세대당 약 100㎡ ⇒ 약 800세대), 업무 25%(40,000㎡ → 1인당 10~15㎡ ⇒ 약 3,000명), 상업 15%, 문화·공공 10%
- 인구 유발: 세대×평균 가구원수(서울 약 2.1) ⇒ 약 1,700명 + 주간 업무인구

**역산 검증**: 유발 인구로 다시 Layer 2~3을 돌려 학교·공원·주차 수요를 재확인한다. (신규 인구가 기존 인프라를 초과시키면 설계안 스스로가 문제를 만드는 것)

## 4. 용도 배분 결정 기준

| 판단 축 | 질문 |
|---|---|
| 시장성 | 이 입지에서 이 용도가 채워지는가? (공실 리스크) |
| 시간대 보완 | 주간/야간/주말 인구가 상호 보완되는가? |
| 상위계획 | 지구단위계획이 지정한 권장/불허 용도는? |
| 공공성 | 공공기여(공원·공공시설)로 무엇을 내놓는가? |
| 주변 갈등 | 기존 주민과 상충(임대료·교통·소음)은? |

배분율 결정 후 **민감도 1줄**: "주거 비율을 ±10% 조정 시 ○○ 영향" — 심사 질문 방어용.

## 5. 비교 사례 카드 (3~5개 수집)

```
사례명 / 위치·시기:
규모 (면적·연면적·용적률):
프로그램 구성 비율:
공통 원리 (우리 안과 무엇이 같은가):
정량 성과 (방문객·임대율·보행량 등):
차이점·주의 (그대로 이식하면 안 되는 이유):
출처 [신뢰도]:
```
사례 선택 기준: ① 유사 규모 ② 유사 입지 유형(역세권/이전적지 등) ③ 검증 가능한 성과 수치 존재. 해외 1 + 국내 2 조합이 설득력 좋다.
