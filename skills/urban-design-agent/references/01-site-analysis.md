# 01. 대상지 분석 (Site Analysis)

> 목표: 대상지를 **레이어로 분해**해 객관적으로 이해하고, 정량 근거가 붙은 문제 목록을 만든다.
> 분석은 설계의 절반이다. 좋은 분석은 설계안을 거의 자동으로 도출한다.

---

## 1. 분석 스케일 3단계 (줌아웃 → 줌인)

| 스케일 | 범위 | 확인 사항 |
|---|---|---|
| 광역 (City) | 시·구 | 도시기본계획상 위상, 중심지 체계, 광역 교통축 |
| 지구 (District) | 반경 1~2km | 생활권 계획, 지구단위계획, 주변 개발사업, 역세권 여부 |
| 대상지 (Site) | 부지 + 인접 블록 | 필지·건물·가로 상세 |

**상위 계획 확인이 최우선.** 지구단위계획·생활권계획에 이미 방향이 정해져 있으면 그것이 가장 강력한 설계 논거가 된다 (예: "○○역세권 지구단위계획(연도)이 본 부지를 ○○ 거점으로 지정").

---

## 2. 레이어별 수집 항목과 방법

### A. 역사·배경 (최우선)
- 개발 시기·계획 의도, 50~100년 전 도시 구조, 주요 변화 타임라인, 남은 역사 자산
- 방법: 국토지리정보원 구지형도, 항공사진 아카이브, 지자체 시사(市史), 뉴스 아카이브

### B. 물리 레이어
| 항목 | 수집 방법 | 표현 |
|---|---|---|
| 토지이용 | 토지이음(eum.go.kr), 현장 | 용도 색상 맵 |
| 건물 용도 | 건축데이터민간개방(open.eais.go.kr) | 용도 맵 |
| 건물 노후도 | 건축물대장 사용승인연도 | 30년 이상 해칭 |
| 건물 높이·층수 | 건축물대장, 항공사진 | 높이 레이어 |
| 필지 구조 | 연속지적도 | Figure-ground |
| 도로 위계 | 도로명주소 기본도 | 간선/집산/국지 구분 |
| 보행망 | 현장답사 + 로드뷰 | 보행 네트워크 + 단절점 |
| 녹지·오픈스페이스 | 위성사진, 공원 데이터 | 녹지 분포 + 접근권 |
| 지형·경사 | 수치지형도 DEM | 등고/경사도 |

### C. 사회 레이어
| 항목 | 출처 |
|---|---|
| 인구 규모·연령·가구 | KOSIS(kosis.kr), 행안부 주민등록 통계 |
| 유동인구·생활인구 | 서울시 생활인구(data.seoul.go.kr), SKT 지오비전 |
| 직주 패턴 | 통계청 통근통학 자료 |
| 사업체·종사자 | 전국사업체조사 |
| 지가·임대료 | 공시지가(부동산공시가격알리미), 상권분석(소상공인마당) |

### D. 인프라 레이어
교육 / 의료 / 상업(마트·시장) / 문화(도서관·공원·커뮤니티) / 교통 결절점(지하철역·버스 정류장)
→ 각 시설에서 **도보 5/10/15분 등시선(isochrone)** 을 그려 커버리지 공백을 찾는다.
(간이법: 도보 5분≈400m, 10분≈800m, 15분≈1,200m 반경 — 단, 실보행 거리는 직선의 약 1.3배)

## 3. 분석 기법 툴킷

### 3.1 Figure-Ground (건물-비건물 흑백도)
- 건물=검정, 나머지=흰색. 도시 조직(urban fabric)의 밀도·패턴·단절을 한눈에 드러냄
- 읽는 법: 격자형/유기형/대가구형 패턴 구분, 보이드(공백)의 형태가 "공간"인지 "버려진 틈"인지

### 3.2 Kevin Lynch 도시 이미지 5요소
| 요소 | 정의 | 분석 질문 |
|---|---|---|
| Path (통로) | 이동 채널 | 주 보행축은? 끊긴 곳은? |
| Edge (경계) | 단절선 (철도·하천·간선) | 무엇이 동네를 가르는가? |
| District (지구) | 성격이 동질한 면 | 어디까지가 '한 동네'인가? |
| Node (결절) | 활동이 모이는 점 | 사람이 모이는 곳은? 비어있는 결절은? |
| Landmark (랜드마크) | 시각 기준점 | 방향감을 주는 요소가 있는가? |
→ 5요소 다이어그램 1장으로 대상지 구조를 요약할 수 있다.

### 3.3 Gehl PSPL (Public Space Public Life) 조사
- **공간 조사**: 가로 단면, 1층부 용도(활성/비활성 파사드 비율), 앉을 곳, 그늘
- **생활 조사**: 시간대별 보행량 카운트(평일/주말 × 오전/오후/저녁), 체류 행위 매핑(서기/앉기/놀기)
- 핵심 지표: **활성 파사드 비율** (1층이 투명하고 출입 빈번한 구간 / 전체 가로 길이), **체류 대 통과 비율**
- 현장 불가 시: 로드뷰 시계열 + 생활인구 데이터로 대체하고 한계 명시

### 3.4 SWOT → 전략 연결
| | 기회(O) | 위협(T) |
|---|---|---|
| **강점(S)** | SO: 강점으로 기회 활용 | ST: 강점으로 위협 방어 |
| **약점(W)** | WO: 기회로 약점 보완 | WT: 최악 회피 |
→ SWOT은 나열로 끝내지 말고 반드시 SO/WO/ST/WT 전략 문장까지 도출.

### 3.5 접근성 분석 (커버리지 맵)
1. 시설 위치 점 찍기 → 2. 400/800/1,200m 버퍼 → 3. 버퍼 밖 인구 추산 → 4. "전체 인구의 ○○%가 ○○에 도보 15분 내 접근 불가"

## 4. 문제 도출 — 6범주 분류

수집 데이터를 아래로 분류하고, **각 문제마다 정량 근거 1개 이상** 필수:

```
접근성  : 도보 15분 내 도달 불가 시설 → "인구 ○%가 도서관 15분 밖"
연결성  : 끊긴 보행로·단절 녹지 → "○○로가 보행축을 ○m 단절"
혼재    : 용도 상충 → "주거-공업 혼재 필지 ○개"
노후    : 30년 이상 건물 → "전체의 ○%"
밀도    : 과밀/저밀 → "용적률 실현율 ○% (한도 대비)"
형평성  : 특정 인구 배제 → "고령자 보행 가능 반경 내 의원 0개"
```

문제 우선순위 매기기: **영향 인구 × 심각도 × 해결 가능성** 3축으로 상위 1~3개만 핵심 문제로 채택.
