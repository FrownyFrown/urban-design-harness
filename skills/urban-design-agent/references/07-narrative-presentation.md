# 07. 내러티브·발표 (Narrative & Presentation)

> 목표: 설계를 "현황(문제) → 개념(방향) → 계획(해결) → 효과(검증)" 이야기로 전달한다.
> 심사자는 도면이 아니라 **논리의 끊김 없음**을 평가한다.

---

## 1. 스토리 골격 — 1·3·5 구조

- **1문장 피치**: "[대상지]는 [핵심 문제]를 안고 있고, 우리는 [전략]으로 [효과]를 만든다."
- **3개 키 메시지**: 문제 1 + 전략 1 + 효과 1 — 발표 내내 반복
- **5단 흐름**: 훅(현장의 한 장면) → 문제(데이터) → 전환("그래서 우리는") → 해법(계획) → 증명(수치)

훅 작법: 통계가 아니라 장면으로 시작. "이 사거리에서 초등학생이 학교까지 가려면 8차선을 두 번 건너야 합니다" > "보행환경이 열악합니다".

---

## 2. 발표 스크립트 템플릿 (5분 기준 — 비례 조정 가능)

```
오프닝 30초 : 장면 훅 + "핵심 문제는 ○○입니다" + 1문장 피치
P1    1분   : 현황 → 문제 (수치 2~3개, 출처 구두 언급: "통계청에 따르면…")
P2    1분   : 접근 → 이론 연결 ("페리가 제시한 400m 단위를…") + 사례 1개
P3    1.5분 : 설계안 — 구조 다이어그램부터 설명 후 평면으로 (큰 것→작은 것)
P4    1분   : 효과 — Before/After + 핵심 수치 3개
클로징 30초 : 키 메시지 3개 반복 + 비전 한 장면
```

규칙: 패널당 메시지 1개만 / 지도·차트를 가리키며 / 숫자엔 출처 / "~인 것 같습니다" 금지(분석했으면 단정형).

시간별 환산: 3분 발표 = P1·P2 압축(각 30초), 10분 = P3에 가로 단면·Phasing 추가.

---

## 3. 예상 질문 Top 10 + 방어 구조

방어 답변 공식: **인정(부분) → 근거 → 설계 반영 지점**

| 질문 | 방어 요지 |
|---|---|
| 1. 데이터 출처가 뭔가 | 출처 즉답 + 신뢰도 등급 언급 (이걸 못 하면 전체 신뢰 붕괴) |
| 2. 실현 가능성은? 돈은 누가? | 사업 방식 + Phasing + 1단계는 공공 저비용 |
| 3. 용적률/법규 검토했나 | 용도지역·조례 한도 수치 즉답, 완화 경로 |
| 4. 기존 주민·상인은? | 영향 분석 1줄 + Preserve 항목 제시 |
| 5. 왜 이 시설인가 (다른 거 말고) | 4-Layer 중 Layer 2 수요 공백 데이터 |
| 6. 수요 예측이 과하지 않나 | 산정식 공개 + 보수적 가정 명시 + 민감도 |
| 7. 비슷한 사례 있나 | 사례 카드 + "차이점과 보정"까지 (그대로 이식 아님 강조) |
| 8. 주차/교통 악화 아닌가 | 유발 교통 역산 + 주차 집약·대중교통 분담 전략 |
| 9. 이 이론이 여기 맞나 | 모델의 전제 조건과 대상지 조건 매칭 표 |
| 10. 한 가지만 한다면? | 1단계 앵커를 즉답 (우선순위 사고 검증 질문) |

준비 규칙: 발표 전 자기 안의 **가장 약한 고리 3개**를 스스로 적고 답을 만들어 둔다. 심사자는 거의 항상 그곳을 찌른다.

---

## 4. 문서형 산출물 (보고서·제안서) 목차 표준

```
1. 요약 (1p — 1문장 피치 + 키 수치 3개 + 마스터플랜 1장)
2. 대상지 분석 (레이어 + 문제 정의)
3. 계획 방향 (이론·사례·컨셉)
4. 마스터플랜 (구조→동선→오픈스페이스→블록→프로그램)
5. 효과 (지표 Before/After)
6. 실행 계획 (법규·사업방식·Phasing)
부록: 근거-주장 매핑 테이블, 출처 목록(APA)
```
요약 1페이지만 읽혀도 통하게 쓴다 — 의사결정자는 요약만 읽는다.

## 5. 청중별 조정

| 청중 | 강조점 | 줄일 것 |
|---|---|---|
| 교수·심사위원 | 논리 일관성, 이론 정합, 출처 | 화려한 렌더링 |
| 공무원·발주처 | 상위계획 정합, 공공기여, 민원 리스크 | 이론 강의 |
| 주민 | 내 삶의 변화(Before/After), 일정 | 전문 용어 전부 |
| 투자자·디벨로퍼 | 프로그램 시장성, 수익 구조, Phasing | 형평성 담론 과다 |
