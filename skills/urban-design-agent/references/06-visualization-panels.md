# 06. 시각화·패널 제작 (Visualization & Panels)

> 목표: 분석·설계를 시각 산출물로 변환한다. 우선순위: **다이어그램 > 지도 > 차트 > 텍스트**.
> 패널은 "읽는 문서"가 아니라 "3m 거리에서 30초 안에 핵심이 전달되는 화면"이다.

---

## 1. 표준 4패널 구성과 레이아웃

### Panel 1 — 대상지 분석 ("문제는 ○○이다")
```
[위치 맥락 지도 1/3] [역사 타임라인 2/3]
[토지이용도 1/3] [교통·보행 현황 1/3] [인구 차트 1/3]
[문제점 요약 — 전체 폭]
```
필수: 광역→줌인 위치도, 역사 배경(50년+), 표준색 토지이용도, 정량 근거 붙은 문제 3~5개

### Panel 2 — 개념·전략 ("우리는 ○○로 접근한다")
```
[핵심 문제 한 문장 — 전체 폭, 크게]
[컨셉 다이어그램 1/2] [이론 근거 1/2]
[비교 사례 카드 2~3 — 전체 폭]
```

### Panel 3 — 마스터플랜 ("이렇게 바뀐다")
```
[배치도 2/3 — 가장 크게] [범례·설명 1/3]
[구조 다이어그램] [동선 체계] [오픈스페이스 네트워크]
```
필수: 스케일바·방위·범례, 주요 시설 레이블, (가능하면) 가로 단면 1개

### Panel 4 — 효과 검증 ("그 결과 ○○이 좋아진다")
```
[15분 접근성 커버리지 맵 1/2] [Before/After 1/2]
[시설 면적 근거표 1/2] [이용 시나리오 1/2]
```
필수: 동심원(5/10/15분), 같은 스케일·같은 뷰의 Before/After, 핵심 수치 3개 크게, 전 수치 출처

## 2. 그리드·타이포·색상 규칙

### 그리드 (A3 기준, A1은 비례 확대)
- 판형 420×594mm, 여백 15mm, 3컬럼, 거터 8mm → 컬럼폭 약 124mm
- 정보 흐름: 좌→우, 상→하. 가장 중요한 요소는 좌상단/중앙상단
- 인접 요소 간격 8mm+, 텍스트 블록 컬럼 정렬·넘침 금지

### 타이포그래피
| 레벨 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| H1 | 18~22pt | Bold | 패널 제목 |
| H2 | 14~16pt | Medium | 섹션 |
| H3 | 10~12pt | Regular | 캡션·레이블 |
| Body | 9~11pt | Regular (행간 1.4) | 본문 |
| Caption | 8~9pt | Regular | 출처·주석 |
폰트 2종 이내. 권장: 제목 Montserrat/Noto Sans KR Bold, 본문 Source Sans Pro/Noto Sans KR.

### 색상 — 60-30-10
- 60% 중립 배경(흰·연회색) / 30% 보조(다이어그램·구분) / 10% 강조 1색
- 강조색은 패널 4장 전체에서 동일하게 — "이 색 = 우리의 제안"으로 학습시킨다

### 토지이용 표준색
주거 #F5C542 / 상업 #E07B3A / 공업 #6B9EC7 / 녹지 #5DAA6B / 공공 #9B7BC4 / 도로 #C0C0C0
(프로젝트 고유 팔레트를 쓸 경우 — 예: 5단 블루 그라데이션 — 4패널 전체 일관 적용)

## 3. 다이어그램 유형별 작법

| 유형 | 내용 | 작법 포인트 |
|---|---|---|
| 구조 다이어그램 | 축·결절·경계 | 배경 지도는 10~20% 투명도로 죽이고 기호만 강하게 |
| 동선 다이어그램 | 보행/차/자전거 | 레이어별 분리 소도 3개 > 한 장에 다 겹치기 |
| 컨셉(버블) | 프로그램 관계 | 면적 비례 원 + 인접성 화살표 |
| Before/After | 효과 비교 | **같은 뷰·스케일·범례** 필수, 차이만 강조색 |
| 동심원 접근성 | 5/10/15분 | 중심점 명시, 반경 수치 직접 표기 |
| 단면도 | 가로·매싱 | 사람 실루엣으로 스케일 제공, 치수선 |
| 단계(Phasing) | 1·2·3단계 | 같은 베이스맵에 단계별 채움 누적 |

공통 규칙: 모든 지도에 **범례·스케일바·방위**. 모든 차트에 **출처(APA)**.

## 4. 데이터 차트 선택

| 데이터 | 차트 |
|---|---|
| 구성 비율 (인구·용도) | 도넛/파이 (항목 5개 이하) |
| 항목 간 비교 (접근시간) | 수평 막대 |
| 시계열 (인구 변화) | 선 |
| 절댓값 비교 | 수직 막대 |
| 공간 커버리지 | 동심원/등시선 맵 |
| 2변수 관계 | 산점도 |
원칙: 차트 1개 = 메시지 1개. 제목을 결론형으로 ("고령 인구 10년간 2배" — "연령별 인구 현황" ✕).

## 5. 제작 도구별 워크플로

| 산출물 | 도구 | 비고 |
|---|---|---|
| 차트·다이어그램 | SVG 직접 생성 / matplotlib | SVG가 패널 삽입에 유리 (벡터) |
| 패널 조판 | HTML/CSS → PDF, 또는 일러스트레이터용 에셋 납품 | A3 @300dpi = 4961×7016px |
| 지도 | QGIS/일러 베이스 + 오버레이 | 에이전트는 오버레이 설명서·범례 제작 담당 |
| 발표 슬라이드 | pptx 스킬 연계 | 패널 콘텐츠 재활용 |

SVG 제작 시 규칙: viewBox 실측 비례, 폰트 fallback 지정(`Noto Sans KR, sans-serif`), 텍스트는 path 변환하지 않음(수정 가능성), 색상은 변수처럼 상단 주석에 팔레트 선언.
