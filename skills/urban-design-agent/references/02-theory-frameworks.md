# 02. 이론·프레임워크 총람 (Theory & Frameworks)

> 목표: 분석된 문제에 맞는 이론 모델을 선택하고, 원리·수치·실패 교훈까지 알고 적용한다.
> 이론은 장식이 아니라 **설계 결정의 근거**다. "왜 이렇게 했나?"에 대한 답이 이론에서 나와야 한다.

## 1. 근린·생활권 모델

### 1.1 페리 근린주구 (Clarence Perry, 1929)
원리 6가지: ① 초등학교 1개 지원 인구(약 5,000명) 규모 ② 간선도로 경계·통과교통 차단 ③ 면적 10% 오픈스페이스 ④ 중심부 학교·커뮤니티 ⑤ 경계부 상업 ⑥ 내부 순환형 도로
- 적정: 반경 400m(도보 5분), 약 65ha
- 비판: 자족성 과장, 사회적 분리 조장 우려 → 현대에는 "시설 배치 단위"로만 차용

### 1.2 래드번 (Stein & Wright, 1929, NJ)
- 핵심: 보행-차량 완전 분리. 슈퍼블록 + 쿨데삭(서비스 전용 막다른 길) + 내부 그린웨이 + 입체 횡단(지하도)
- 구조: 20채=1엔클레이브, 3엔클레이브=1블록, 5블록=1슈퍼블록, 도보권 반경 800m
- 수치: 149에이커(약 60만㎡)에 단독 430+연립 90채, 내부공원 23에이커, 도로 면적 25% 절감
- **실패 교훈**: 주민은 그린웨이보다 쿨데삭(차 쪽)을 더 사용 / 공유 녹지보다 개인 마당 선호 / 감시 부재 구간 범죄 우려 → 그린웨이에는 **자연 감시(주거 전면 배치, 1층 활성용도)** 필수

### 1.3 15분 도시 (Carlos Moreno, 파리 적용)
- 일상 기능 6가지(거주·일·상업·의료·교육·여가)를 도보·자전거 15분 내에
- 환산: 도보 5분≈400m / 10분≈800m / 15분≈1,200m / 자전거 15분≈3,000m
- 주의: "15분"의 주체에 따라 반경이 달라진다 (노인·어린이는 축소) → **타겟 인구 선행 정의**
- 비판 대응: 게토화 우려 → 광역 연결성(대중교통)과 병행 설계로 답한다

### 1.4 서울 생활권 계획 (2040 서울도시기본계획 계열)
| 시간권 | 단위 | 시설 |
|---|---|---|
| 5분권 | 블록 | 소공원, 편의점, 어린이집 |
| 10분권 | 동 | 초등학교, 의원, 마트 |
| 15분권 | 2~3개 동 | 병원, 도서관, 중학교 |
- 일상생활권: 1~2개 동, 인구 2~3만, 보행 30분(약 1km) 권역
- 한국 과제·실무에서는 이 기준이 **공식 근거**로 가장 안전

## 2. 가로·공공공간 이론

### 2.1 제인 제이콥스 (Jane Jacobs, 1961)
도시 다양성 4조건: ① 용도 혼합(시간대별 인구 유지) ② 작은 블록(코너가 많을수록 선택 경로↑) ③ 노후·신축 건물 혼재(임대료 스펙트럼) ④ 충분한 밀도
- "거리의 눈(eyes on the street)": 가로 안전은 CCTV가 아니라 가로를 향한 창·출입구·체류 인구가 만든다
- 적용: 블록 길이 단축(이상적 60~120m), 1층 점포 연속성, 슬럼화 방지용 점진 개발

### 2.2 얀 게일 (Jan Gehl)
- 활동 3유형: **필수 활동**(어떤 환경에서도 발생) / **선택 활동**(환경이 좋아야 발생) / **사회 활동**(앞 둘의 파생)
  → 공공공간의 질은 **선택 활동량**으로 측정된다
- 인간 척도: 5km/h 속도의 도시. 시각 인지 한계 — 얼굴 식별 25m, 디테일 감상 10m 이내
- 1층부(ground floor)가 도시 경험의 90%: **활성 파사드** — 단위 폭 5~6m마다 출입구, 투명도 60%+
- 12 품질 기준: 보호(교통·범죄·기후로부터) 3 + 쾌적(걷기·서기·앉기·보기·듣기·놀기) 6 + 즐거움(스케일·기후 향유·미적 질) 3

### 2.3 윌리엄 화이트 (W. Whyte) — 소공간 사회생활
- 사람들은 "앉을 곳이 있는 곳"에 모인다. 이동식 의자 > 고정 벤치
- 광장 성공 요인: 앉을 자리(가로 1m당 권장), 햇빛, 물, 나무, 음식, **거리와의 관계(단차 최소화)**
- "사람을 끌어들이는 것은 다른 사람들이다" — 빈 광장을 만들지 말 것

### 2.4 바르셀로나 수퍼블록 (Superilles)
- 9개 블록(약 400×400m)을 묶어 내부 차량 제한(10km/h, 거주자만), 외곽으로 통과교통 우회
- 래드번의 현대적·기존시가지형 변형. 신규 개발이 아닌 **기존 격자에 적용 가능**한 것이 강점
- 보고된 효과 방향: 소음·대기질 개선, 가로 활동 증가 (수치는 적용지마다 상이 — 인용 시 출처 필수)

## 3. 교통·개발 결합 모델

### 3.1 TOD (Transit-Oriented Development, Peter Calthorpe)
- 역 중심 반경 400~800m에 고밀 복합용도 + 보행 우선 설계
- 밀도 그라데이션: 역 코어(최고밀) → 400m(중밀) → 800m(저밀)
- 핵심 요소: ① 역 직결 보행 동선 ② 1층 상업 연속 ③ 주차 최소화(상한제) ④ 복합용도로 양방향 통행 수요
- 한국 적용: 역세권 활성화사업, 역세권 청년주택 등 제도와 연결 가능

### 3.2 복합용도개발 (Mixed-Use Development)
- 수직 혼합(한 건물 내 층별) vs 수평 혼합(블록 내 건물별)
- 시간대 보완 조합: 주거(야간) + 오피스(주간) + 상업(전일) + 문화(주말) → 24시간 활력
- 주의: 용도 간 갈등(소음·하역) → 동선·층 분리로 해결

### 3.3 뉴어바니즘 / 압축도시
- 뉴어바니즘 헌장 요지: 보행권 근린, 전통 가로 패턴, 대중교통 연계, 다양한 주택 유형 혼합
- Transect 개념: T1(자연)→T6(도심 코어) 단면 위에 밀도·형태를 연속 배치
- 압축도시(Compact City): 외연 확산 억제 + 기성시가지 고밀화 — 한국 도시정책의 기본 기조

## 4. 형태 기반 도구

### 4.1 패턴 랭귀지 (Christopher Alexander, 1977)
- 253개 패턴 중 도시설계 빈용: 활동 결절(30), 보행 거리(100), 작은 광장(61 — 폭 18m 이하가 친밀), 건물 정면이 만드는 가로(122), 모서리 가게(87)
- 사용법: 패턴을 "체크리스트"가 아니라 "문제-해법 쌍"으로 인용

### 4.2 Form-Based Code 사고법
- 용도 규제가 아닌 **형태 규제**: 건축선, 저층부 투명도, 입면 분절, 주차 위치(후면)
- 지구단위계획 지침 작성 시 이 어휘를 쓰면 실무적 설득력↑

## 5. 모델 선택·결합 가이드

| 분석된 핵심 문제 | 권장 조합 |
|---|---|
| 주거지 보행 안전 | 래드번 구조 + 게일 가로 기준 |
| 기성시가지 차량 과잉 | 바르셀로나 수퍼블록 + 제이콥스 블록 분할 |
| 시설 접근 불평등 | 15분 도시 지표 + 서울 생활권 기준(공식 근거) |
| 역세권 저이용 부지 | TOD 밀도 그라데이션 + 복합용도 + 1층 활성화 |
| 대형 이전적지(공장·기관) | TOD/복합용도 + 오픈스페이스 네트워크 + 단계 개발 |
| 광장·공원이 비어 있음 | 화이트 소공간 원칙 + 게일 12 기준 |

**결합 원칙**: 구조는 1개 모델(뼈대), 기준은 1개 모델(검증 지표), 디테일은 가로 이론(게일/제이콥스)에서. 3개 초과 인용은 산만해진다.

**인용 형식**: 모델명 + 제안자 + 연도 + 핵심 수치 1개. 예: "페리의 근린주구(1929)가 제시한 도보 5분(400m) 단위를 적용하여…"
