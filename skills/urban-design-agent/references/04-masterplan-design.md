# 04. 마스터플랜 설계 (Masterplan Design)

> 목표: 프로그램을 공간으로 번역한다. 결정 순서가 곧 방법론이다:
> **구조 → 동선 → 오픈스페이스 → 블록·매싱 → 프로그램 배치 → 엣지.**

---

## 1. 구조 설계 (Structure)

대상지의 뼈대를 3요소로 정의한다:
- **축(Axis)**: 주 보행축·시각축. 기점과 종점이 명확해야 한다 (예: 역 ↔ 하천, 공원 ↔ 광장)
- **결절(Node)**: 축이 교차하거나 꺾이는 곳 = 광장·앵커 시설 자리
- **경계(Edge)**: 대상지가 주변과 만나는 선 — 단절할 곳과 열 곳을 구분

구조 다이어그램 1장(축 화살표 + 결절 원 + 경계 선)이 마스터플랜의 요약본이다. 이 다이어그램이 어색하면 평면도 백 장도 소용없다.

**컨셉 형태 어휘**: 선형 스파인(긴 대상지), 중심 코어형(정방형), 그리드형(대형 부지), 클러스터형(지형 제약지). 컨셉명은 형태+의미 결합 (예: "Connecting the Dots" — 분산 자산을 선형 축으로 연결).

---

## 2. 동선 체계 (Movement) — 보행 우선 순서로 설계

```
1. 보행 주축 (역·정류장 → 핵심 시설, 최단·무단차)
2. 보행 보조망 (블록 관통로 — 블록 길이 120m 초과 시 중간 통로 필수)
3. 자전거 (주축과 분리 또는 폭 확보, 결절부 주차)
4. 차량 (외곽 우회 원칙, 내부는 접근 전용)
5. 서비스·하역 (이면 또는 시간제, 보행축과 절대 교차 금지)
6. 주차 (지하 집약 또는 외곽 집중 — 건물별 분산 금지)
```

원칙:
- 보행 동선은 **목적지 직결 + 비 가림 + 1층 활성용도 연접** 3조건
- 차량-보행 교차 불가피 지점 → 고원식 횡단보도(보도 높이 유지) 또는 입체화
- 쿨데삭·루프 도로는 통과교통 차단용 — 단 막다른 끝에 회차 공간(반경 6m+)

## 3. 오픈스페이스 (건물보다 먼저 그린다)

위계 설계:
| 위계 | 규모 | 역할 |
|---|---|---|
| 중심 광장/공원 | 결절부, 앵커 | 전체의 거실 |
| 선형 녹지(그린웨이) | 주축 병행 | 연결 + 일상 보행 |
| 포켓공간 | 250~500㎡, 블록마다 | 5분권 일상 |
| 사적 외부공간 | 중정·테라스 | 거주자 전용 |

설계 규칙:
- **네트워크로 연결**: 고립된 녹지는 면적 합산만 될 뿐 작동하지 않는다. 모든 오픈스페이스가 보행로로 이어지게
- 광장 크기: 폭 18~25m가 친밀한 스케일(Alexander 61 / 게일 25m 얼굴 인식 한계). 100m 넘는 광장은 비는 광장
- 광장 가장자리는 반드시 활성용도(카페·상점·도서관 입구). 4면 중 최소 2면
- 일조: 주 체류 공간은 남측 개방 — 매싱 결정과 동시 검토
- **자연 감시**: 모든 공공공간이 주거·업무의 창과 마주 보게 (래드번 실패 교훈)

형태 어휘 예: 1/4원 광장(코너 결절 + 두 가로를 동시에 안음), 중정형 매스(외부 가로벽 유지 + 내부 정온), 선큰(지하 상업과 지상 연결).

## 4. 블록·매싱 (Block & Massing)

### 블록 타입 제원
| 타입 | 제원 | 장점 | 약점 |
|---|---|---|---|
| 페리미터(중정형) | 60~120×60~120m, 깊이 12~16m 동 | 가로벽 형성+내부 정온 | 코너 평면 어려움 |
| 판상형 평행배치 | 동간 인동거리(높이×0.8~1.0배) | 채광·통풍, 한국 주거 선호 | 가로 단절, 단조 |
| 타워+포디움 | 저층 기단(상업) + 타워(주거/업무) | 고밀+1층 활력 양립 | 그림자·풍환경 |
| 소필지 연속 | 폭 6~12m 개별 건물 | 다양성·점진 개발(제이콥스) | 대형 앵커 불가 |

### 매싱 원칙
1. **밀도 그라데이션**: 역/간선 쪽 고층 → 기존 저층 주거 쪽으로 단계적 하향 (스카이라인 단면도로 검증)
2. **저층부 5원칙 (게일)**: 출입구 5~6m마다 / 투명도 60%+ / 단차 최소 / 처마·차양 / 용도 잘게 분절
3. 타워 배치: 가로 모퉁이·축 종점에 — 랜드마크는 위치가 만든다
4. 일조·사선: 정북 일조(전용·일반주거 인접 시), 채광창 이격 — 법규 체크는 05 참조
5. 풍환경: 고층 하부 빌딩풍 → 포디움으로 완충

### Preserve / Update / Add 적용
기존 시가지 설계 시 전면 철거 전제 금지:
```
Preserve: 가로 패턴·노포·수목·역사 자산 → 구조에 편입
Update  : 노후 but 위치 좋은 건물 → 리모델링·용도 전환
Add     : 공백 필지·이전적지 → 신축
```

## 5. 프로그램 배치 — 인접성 매트릭스

| | 주거 | 업무 | 상업 | 문화 | 학교 | 공원 |
|---|---|---|---|---|---|---|
| 주거 | — | △ | ○ | ○ | ◎ | ◎ |
| 업무 | △ | — | ◎ | ○ | △ | ○ |
| 상업 | ○ | ◎ | — | ◎ | △ | ◎ |
| 문화 | ○ | ○ | ◎ | — | ◎ | ◎ |
◎ 시너지(붙여라) ○ 무난 △ 완충 필요(소음·하역·통학 안전)

배치 휴리스틱:
- 상업은 보행량 따라: 역 출구·주축 1층에 선형으로 (면형 상업몰보다 가로형)
- 학교·어린이집: 간선도로에서 한 켜 안쪽, 공원 인접, 통학로에 차량 횡단 최소
- 앵커(도서관·문화시설): 축의 종점·광장 변에 — "걸어갈 이유"를 만든다
- 주거: 정온한 내부 + 남향 우선, 단 가로변 1층은 비주거 활성용도로

## 6. 엣지 처리 (대상지 경계)

| 인접 조건 | 처리 |
|---|---|
| 간선도로 | 완충 녹지 또는 포디움 상업 가로벽 |
| 기존 저층 주거 | 높이 단계 하향 + 골목 스케일 이어받기 |
| 하천·공원 | 최대 개방 — 시각·보행 통로를 경계에 직교로 |
| 철도·고가 | 하부 활용(주차·체육) 또는 데크 연결 |

**대상지는 섬이 아니다.** 경계 밖 200m까지 동선이 어떻게 이어지는지 보여줘야 "지역에 기여하는 설계"가 된다.
