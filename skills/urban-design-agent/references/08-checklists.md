# 08. 품질 게이트 체크리스트 (Quality Gates)

> 각 PHASE를 끝내기 전 통과해야 하는 관문. 에이전트는 PHASE 종료 시 해당 게이트를 자가 점검하고 결과를 1줄로 보고한다.
> 예: "Gate 1 통과 (7/7) — 단, 유동인구는 [추정] 표기로 진행."

---

## Gate 1 — 대상지 분석 완료 조건
- [ ] 상위계획(기본계획·생활권·지구단위계획) 확인 및 정합 메모
- [ ] 3스케일 위치 맥락 정리
- [ ] 물리·사회·인프라 레이어 중 과업 필요분 수집 (결측은 [추정]/[현장확인필요] 표기)
- [ ] 5/10/15분 접근성 분석 수행
- [ ] 문제점 6범주 분류 + 각각 정량 근거 ≥1
- [ ] 핵심 문제 1문장 도출
- [ ] 모든 수치에 출처

## Gate 2 — 컨셉 완료 조건
- [ ] 타겟 인구가 숫자로 정의됨 ("주민" ✕ → "반경 800m 내 30대 1인가구 ○명" ○)
- [ ] 이론 모델 선택 + 선택 이유 1줄 (대상지 조건과 모델 전제의 매칭)
- [ ] 컨셉 1문장: [타겟]+[문제]+[전략]+[비전]
- [ ] 설계 목표 3~5개 (각각 측정 가능한 동사로)

## Gate 3 — 프로그램 완료 조건
- [ ] 모든 시설이 4-Layer 통과
- [ ] 면적 산정식 명시 (인구 × 기준, 기준의 법적 근거)
- [ ] 연면적 배분 ↔ 용적률 한도 정합
- [ ] 유발 인구 역산 검증 (신규 수요가 인프라 초과하지 않는지)
- [ ] 근거-주장 매핑 테이블 완성
- [ ] 비교 사례 ≥3 (차이점·주의 포함)

## Gate 4 — 마스터플랜 완료 조건
- [ ] 구조 다이어그램 1장으로 안이 요약되는가
- [ ] 동선: 보행 주축 무단차·직결 / 서비스와 보행 비교차 / 주차 집약
- [ ] 오픈스페이스: 네트워크 연결 + 가장자리 활성용도 + 자연 감시
- [ ] 매싱: 밀도 그라데이션 단면 검증 / 저층부 5원칙
- [ ] 인접성 매트릭스 위반 없음 (학교 옆 하역장 등)
- [ ] 엣지: 4방향 경계 처리 정의
- [ ] (기성시가지) Preserve/Update/Add 분류

## Gate 5 — 실현성 완료 조건
- [ ] 용도지역·조례 한도 확인 (초과 시 완화 경로 명시)
- [ ] 공공기여 패키지 정의
- [ ] 사업 방식 + 3단계 Phasing (각 단계 자체 완결)
- [ ] 이해관계자 영향·대응 1줄씩

## Gate 6 — 시각화 완료 조건
- [ ] 패널당 핵심 주장 1개 (제목에 반영)
- [ ] 모든 지도: 범례·스케일바·방위 / 모든 차트: 출처
- [ ] 색상 60-30-10, 표준색/팔레트 4패널 일관, 폰트 ≤2종
- [ ] Before/After 동일 뷰·스케일
- [ ] 텍스트 ≤ 패널 면적 30%

## Gate 7 — 발표 완료 조건
- [ ] 1문장 피치 + 3 키 메시지
- [ ] 스크립트 시간 내 (리허설 기준)
- [ ] 약한 고리 3개 자가 식별 + 방어 답변
- [ ] 예상 질문 Top 10 답변 준비

---

## 전체 최종 게이트 (납품 전)
- [ ] 논리 사슬 무결: 문제→분석→전략→설계→효과가 한 줄로 이어짐 (중간에 갑자기 등장한 시설 없음)
- [ ] 숫자 일관성: 같은 수치가 문서 전체에서 동일 (인구·면적·% 교차 검증)
- [ ] 출처 목록(APA) 완비, 신뢰도 표기
- [ ] [추정]·[현장확인필요] 항목 잔여 목록을 사용자에게 보고
