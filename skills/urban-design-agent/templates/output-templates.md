# Templates — 바로 채워 쓰는 산출물 양식

## T1. 설계 브리프 (PHASE 0)
```
대상지     :
면적·경계  :
용도지역   :                    상위계획:
과업 성격  : 과제 / 공모 / 실무 / 탐색
설계 범위  : 필지 / 블록 / 근린 / 지구
산출물     :
마감·제약  :
타겟(가설) :
```

## T2. 문제점 요약표 (PHASE 1)
| # | 범주 | 문제 | 정량 근거 | 출처[신뢰도] | 영향 인구 | 우선순위 |
|---|---|---|---|---|---|---|

## T3. 컨셉 시트 (PHASE 2)
```
핵심 문제 1문장 :
타겟 인구       : (숫자로)
적용 모델       : (모델명, 제안자, 연도) — 선택 이유:
컨셉 문장       : [타겟]을 위해 [문제]를 [전략]으로 해결하는 [비전]
설계 목표       : 1.  2.  3.
```

## T4. 시설 프로그램표 (PHASE 3)
| 시설 | 면적(㎡) | 산정식 | 법정/계획 기준 | 타겟 인구 | Layer2 공백 근거 |
|---|---|---|---|---|---|

## T5. 근거-주장 매핑 (PHASE 3)
| 문제/주장 | 정량 근거 | 정성 근거 | 출처[신뢰도] | 도출 전략 | 발표 한 문장 |
|---|---|---|---|---|---|

## T8. 법규 체크 시트 (PHASE 5)
```
용도지역:            조례 건폐율/용적률 한도:    /
계획 건폐율/용적률:   /        (여유:    %p)
높이 규제 해당 여부: 정북일조 □  가로구역 □  기타 □
지구단위계획: 구역명·결정연도:           정합 메모:
공공기여 패키지:
사업 방식:           Phasing: 1단계        2단계        3단계
```

## T9. 발표 스크립트 골격 (PHASE 7)
```
[오프닝 30초] 장면 훅:
              핵심 문제:
              1문장 피치:
[P1 1분]  수치1:        수치2:        결론:
[P2 1분]  이론 인용:    사례:
[P3 1.5분] 구조 설명 → 평면 설명 순서 메모:
[P4 1분]  Before/After 수치 3개:
[클로징 30초] 키 메시지 3개 반복:
약한 고리 3개 + 방어:
```
