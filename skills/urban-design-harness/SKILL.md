# Urban Design Harness — 오케스트레이션

이 시스템은 **AI가 주도해서 도시설계를 수행**하기 위한 하네스다. 표면 산출물은 판넬, 이면은 전부 명세·버전 관리.

## 불변 원칙 (위반 금지)
1. **판넬 중심** — 모든 결과는 판넬로 표현. 판넬만 봐도 설명돼야 함. 이면은 전부 기록.
2. **명세 우선** — 판넬 각 섹션은 `panel/sections/<id>/SPEC.md`로 명세·버전 관리. 새로 추가된 내용 추적.
3. **단일 귀결** — 모든 논리는 `direction/DIRECTION.md` 하나로 귀결.
4. **논리적 서술 의무** — "기존 문제 → 무엇을 바꾸는가 → 어떤 영향" 서술 필수. 결론만 금지.
5. **피드백 루프** — 단계 종료마다 방향성 재검토. 사후 개선은 자연스러운 일 — 루프로 흡수.
6. **무결성 검증** — verify 통과 후에만 DIRECTION.md 귀결. 연결 문서와 모순 0.
7. **레퍼런스 기반** — 모든 판단(방법론·도구·배치·색상)에 레퍼런스. references/INDEX.md 인용.
8. **완결 세트 선행** — 시작 시 스토리·서술·주제를 완결 세트로 확정. 사후 끼워맞춤 차단.

## 🚨 비약 금지 (verify가 강제)
불확실한 부분은 비약하지 않는다. 🔲 미결정 표기 + 사용자 질의. 근거 없는 가정으로 채우지 않는다.

## 프로세스
대상지 선정 → Site Analysis → Comprehensive Analysis(이슈→이유→영향) → Design Process(문제→변경→영향 서술) → Master Plan(SketchUp contour, 다중 뷰). 각 단계 간 피드백 루프.

## 에이전트 운용 (6종 — 이 플러그인의 agents/)
- **architect**(메인): 섹션 논리→텍스트→판넬 반영 주도. 다른 에이전트 결과를 통합.
- **design**: DESIGN.md 기준 템플릿·영역·크기. 산출물 우선순위 다이어그램>지도>차트>텍스트.
- **verify**: 루프마다 당위성·무결성·완결성·방향성 검증 → `_state/integrity-report.json`. 비약 차단.
- **research**: 분산 데이터 점진·순차 수집 → references/ 축적. 더 나은 안 발견 시 루프 트리거.
- **modeling**: SketchUp·Rhino 등 3D 도구. contour 기반, 1인칭·조감 다중 뷰. (제어 MCP 있으면 직접, 없으면 작업 지침서 산출)
- **critic**: 교수(제3자) 시점 냉철 비평. DIRECTION 귀결 후 투입.

오케스트레이터(메인 루프)는 Agent 도구로 위 에이전트를 위임 호출한다. 단계 산출물이 나올 때마다 verify를 반드시 거친다.

## 섹션 파이프라인 (/ud-section)
1. PANEL_SPEC.md 좌표·크기 확인 → 2. architect: 논리 구성(최우선) → 3. 텍스트 구성 → 4. design 협업: 시각화 형태·템플릿 → 5. 영역 맞춤 SVG/이미지 생성·배치(assets/) → 6. 섹션 SPEC.md 갱신 → 피드백 루프 진입

## 피드백 루프 (/ud-loop)
작업 → DIRECTION 업데이트("지금 방향성? 이전 방향성?") → verify → 통과: DIRECTION.md 귀결+버전 기록(직접 +0.1/간접 +0.01, 타임스탬프, 맥락 구분: 이전/현재/진행중/보관) → critic 비평 → 개선점은 다음 루프 입력. 불일치: 논리 구조 재구성 후 재작업.

## 상태 파일
`_state/direction-pointer.json`(방향성 포인터) / `loop-state.json`(루프 상태) / `integrity-report.json`(검증 결과). 모든 단계 전환 시 갱신.

## 참고 자료 위치
- **레퍼런스(참고용)**: 본 플러그인 동봉 스킬 `urban-design-agent`의 references 9종(분석·이론·프로그램·마스터플랜·법규·패널·발표·체크리스트·용어) — 방법론이 필요할 때만 로드. 정본이 아니라 참고자료다.
- **모든 기록은 로컬 파일 기반** — 외부 서비스(노션 등) 의존 없음. 인스턴스 디렉터리가 SSOT다.

## 🔲 인스턴스별 결정 항목 (임의 결정 금지)
색상 체계 / 판넬 규격·섹션 수 / 크리틱 기준(심사자 페르소나) / 생성형 이미지 허용 여부(기관·공모전 규정 확인) — 해당 단계 진입 전 사용자 질의. /ud-init 시 함께 묻는다.
